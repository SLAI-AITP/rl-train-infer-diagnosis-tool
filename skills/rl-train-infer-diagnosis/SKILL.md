# RL 训推不一致定位

把训推差异收敛到具体算子或实现细节。使用同一次 rollout 的 token，由 train 重放；可复用历史记录，也可主动采集，不要求用户预先保存失败样本。

**本文件统一规定：每一步取得什么指标、如何判读、下一步做什么。** `references/` 只提供数据契约、计算公式、实验与插桩方法、产物格式；不另设诊断结论或流程分支。

随附脚本只计算已对齐 NPZ 的离线指标。真实框架的采集、状态恢复和重放需要按当前版本适配；未执行的框架集成不作为已验证能力。脚本路径相对于本 skill 目录解析。

## 定位循环

初始范围为整个模型。第 2 节选点 → 第 3 节同输入比较 → 第 4 节进入内部 → 在新范围重复第 2、3、4 节：

```text
取得或复用当前范围的中间结果及 cossim
    ↓
先选差异增长最大的层／子模块，再检查首次异常下降处
    ↓
对选中区间做双向同输入比较
    ├─ 差异仍在且可再拆 → 进入该区间内部 → 回到循环起点
    ├─ 两组同输入接近一致 → 检查传播／放大 → 沿相关上游继续循环
    └─ 已到具体算子／实现细节 → 单项干预与端到端验证
```

“进入内部”是缩小分析范围；误差是否被放大，由第 5 节另行判读。保存结果时可同时生成指标；已有正确指标直接用于选点，只有张量时离线补算，不为计算指标重新运行模型。已有适用的重放证据可直接引用；缺少内部观测、条件变化或需要复测时才新增运行。每轮记录当前范围、选中区间、证据和下一步，保留其他候选及已测状态。

## 工作约定

- 主指标为**有效 token 等权平均 cosine**，计算口径见参考文档。记录端到端 Δlogprob 与可取得的 Δp；主要沿 cosine 定位，它解释不了端到端差异时才走辅助路径。
- 保留待诊断场景原始配置。单卡化、关 fusion、升精度、切 eval、改 batch 都属于实验，记录其影响。不同 dtype、并行、cache 或 kernel 不自动等于配置错误。
- 依照实际 forward 选择采集点，不假定固定的 Attention → MoE → FFN 架构。比较同一逻辑 token、对应计算语义和状态；两端分别自由生成的不同轨迹不能用于数值归因。
- 原始指标用于选候选，同输入实验用于检验局部差异，单项干预用于检验端到端作用。训练端是比较基准，不自动代表数学正确性。
- “明显／接近一致”按本次比较精度、适用的同端重复波动及记录的容差判读，不设通用 0.999 阈值，也不要求不同 kernel 位级一致。第 2 节的前序层规则专用于选点，不代替同输入或干预实验的容差。
- 在任务工作区保存产物；有访问方式和实验范围时继续执行。确实缺少代码、入口、权重或算力时先完成可做部分，再仅请求缺少内容。

## 1. 建立样本，做最小可比性检查

**取得的数据。** 按 [采集与指标方法](references/capture-and-metrics.md) 取得两端入口／命令、样本与权重来源、实际 token／前缀／目标位置、有效 token 集、logprob 处理口径和已知执行差异，逐步写入 `run_manifest.json`。未知标未知。

有现成 rollout／trace 时复用并补采；没有记录时，从现有数据选一条或少量 prompt，主动运行 rollout → train replay，不必完整训练一轮或等训练失败。为隔离引擎差异，两端使用同来源 policy 快照，train 在更新前重放或单独加载该快照前向。保留推理侧 prefill／decode 与 cache 路径，复测固定 token 轨迹。用 full-sequence prefill 替代原 decode 属于另一组对照，其结果不能单独证明原路径问题消失。

**根据结果执行。**

| 观测结果 | 下一步 |
|---|---|
| 权重来源、逻辑输入与当前比较语义对应 | 进入第 2 节；不等待完整 kernel 溯源和所有重复实验 |
| 已证实权重版本、输入或评分语义影响可比性 | 标记 `CONFIG_MISMATCH`，报告两端值、证据、影响范围；暂停受影响部分的算子归因，继续其他分析。已有授权时单项对齐重测，否则报告该项；未经重测不宣称解释全部差异 |
| 只有 logprob 处理口径不同，hidden 比较仍有效 | hidden 扫描继续第 2 节；评分问题回到本步对齐 |
| 缺少记录但具备运行条件 | 主动新采集后进入第 2 节，标明新样本与历史场景的关系 |
| 条件暂缺或关键对应关系未查明 | 继续可做的采集／查证，保留未决项；不能把混合了权重变化的差异归因给算子 |

position／attention mask／序列边界要求逻辑上下文对应，不要求张量表示相同。temperature 按实际作用阶段核对：固定 token 后，仅影响采样的温度不同不阻止 hidden 或 raw logprob 比较。batch、TP／EP／PP、dtype、fusion、cache 等保留为候选变量。**router replay 不要求初始开启**，未开启不构成 `CONFIG_MISMATCH`；有证据指向路由后再做单项对照。

## 2. 根据当前范围的指标选候选

**取得的指标。** 按 [指标定义](references/capture-and-metrics.md) 取得各层／子模块的 `C_in、C_out、Dcos、G、n_valid`、逐 token cosine、异常位置；同类前序边界的 `n_prefix、mu_prefix、sigma_prefix、lower、prefix_ready`；端点的 Δlogprob／Δp 汇总及适用的重复波动。需要改代码时用 [插桩方法](references/instrumentation-guide.md)，同时记录插桩前后端点差异和路径变化。

整模型覆盖 embedding、各层输入／输出、final norm、LM head 和评分出口；层内循环只扩展当前范围。已有指标直接复用。G 表示差异增长的绝对增量；其公式、前序统计及端点统计均在参考文档中。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| 存在可判读的正 G | **先选 G 最大的层／子模块，进入第 3 节**。首轮可按单次观测选临时候选；复测后按 G 中位数排序，区分波动。无法分辨先后时保留并列，先查计算顺序较早者 |
| `prefix_ready=true` 且 `C_out < lower` | 标记异常下降；按前向顺序最早触发者作为第二优先候选，最大增长候选之后检查；两者相同则去重 |
| 前序不足、语义不可比、方差近乎零或触发不稳定 | 不据此给出可靠的“首次”结论；保留指标和限制，优先走最大增长路径，必要时补采／复测 |
| 没有可判读的正增长或前序触发，而端点仍有差异 | 检查 embedding、final norm／LM head／评分出口及漏采区间；cosine 仍无法解释时进入第 6 节 |
| token／表示未对齐，或插桩显著改变端点／执行路径 | 修复采集和对齐，记录改变条件；原路径证据可取得后再选点 |
| 有效零范数、NaN／Inf 或指标为空 | 进入第 6 节处理指标有效性，不把空值或有限子集均值当全体一致 |

“首次差异”指**相对前面全部层的 cosine 基线首次异常下降**。默认 `t=3、min_prefix_layers=3`；不包含当前层、不用滑动窗口。前 3 层仍参与最大增长扫描。σ=0 时 `lower=mu`，微小下降仅作临时候选，按精度与复测核验。确认首次位置时，各次复测均须在该层触发、更早可判读层不触发；缺失历史或触发层变化时报告范围。该规则是启发式，不声称固定置信度；未触发不证明没有累计差异。

保留其余异常及最终异常 token，不假定差异单调、不直接二分唯一源头。最大 G、首次异常下降、最低输出 cosine 都只是选点证据。

## 3. 对选中区间做双向同输入比较

**取得的指标。** 对上一步选中的层或子模块，按 [重放实验方法](references/replay-and-amplification.md) 取得四组输出及以下指标：

| 指标 | 含义 |
|---|---|
| `R_T、R_I` 及相关误差统计 | 各端自重放输出与自身原 trace 的对应程度 |
| `S_T、S_I` | 分别固定训练侧输入、推理侧输入时，两端输出的平均 cosine |
| `C_in、P_T、P_I` | 两份原始输入的 cosine，以及固定各端实现、只改变输入时的输出 cosine |
| `C_natural` | 原始两端输入分别经过各自实现后的输出 cosine |

另取得完整输入／状态对应记录和重放路径信息。自重放验收与同输入“接近一致”的判定同时检查方向和幅值误差；仅 cosine 接近 1 不足以通过验收。完整同输入包含 live inputs、residual、位置、mask、历史 cache 等；只换 hidden 而留不同历史状态不算严格同输入。边界 cast 和适配也属于当前受测区间。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| R_T／R_I 或幅值误差未通过自重放容差，或输入／状态／路径控制无效 | 标记 `REPLAY_INVALID`，先修复重放器；条件仍不足时第 8 节交付已知区间，不做局部归因 |
| 任一 S_T／S_I 显示可重复、超出本步容差的差异 | 标记 `LOCAL_SOURCE_CANDIDATE`，进入第 4 节；另一组接近一致不能排除它 |
| 两组 S_T／S_I 都接近一致 | 标记 `PROPAGATION_CANDIDATE`，进入第 5 节；不直接称为纯放大器 |
| 同输入差异与同一实现的跨输入响应同时明显 | 继续第 4 节拆局部来源，同时保留 P_T／P_I 并按第 5 节记录传播作用；两种角色可以共存 |
| cosine 接近 1，但已有证据表明端点仍不一致 | 第 6 节；接近 1 不等于数值相同 |

同输入的微小差异仅产生局部候选，不自动代表本次端到端主因；第 7 节另证其作用。

## 4. 进入选中区间内部，继续同一循环

**取得的指标。** 按 [层内观测与算子实验方法](references/operator-localization.md) 和 [插桩方法](references/instrumentation-guide.md)，在父区间的同输入运行中取得内部各采集点的中间结果及 cossim。汇总各子模块的 `C_in、C_out、G`、适用的前序统计、完整实际输入和源码／kernel 位置。已有条件匹配的 trace 和指标直接复用，只补缺失观测。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| 内部已有可用指标 | **直接按第 2 节规则选具体子层／子模块，再进入第 3 节**；不额外重跑模型计算已有指标 |
| 选中子模块同输入仍有差异且可再拆解 | 把它设为当前分析范围，重复第 4 节取内部指标 → 第 2 节选点 → 第 3 节同输入比较 |
| 选中子模块两组同输入都接近一致 | 进入第 5 节，随后将尚未解释输入差异的相关上游作为新的范围 |
| 已缩小到具体算子／实现细节 | 检查精度、cast、归约顺序、scale／epsilon、位置／mask、路由、量化或通信等具体差别；受控实验支持机制时记 `LOCAL_SOURCE_CONFIRMED`，进入第 7 节 |
| 只能观察整个 fused 区间 | 保留该区间和实现限制；受控变体／拆分对照需验证与原路径的关系。无法再拆且证据不足时第 8 节交付，不指认不可见的内部算子 |
| 父区间差异存在，但内部观测解释不了 | 补查遗漏操作／分支、采集语义和出口；仍不能解释时第 6 节 |

父区间输入相同不保证子区间输入相同，每次下降都重新控制选中子模块的实际输入。每项实验记录假设、固定项、改动项及不同结果对应的下一步；否定假设时更新候选。

## 5. 判断传播／放大，返回上游

**取得的指标。** 复用第 3 节的 `S_T、S_I、C_in、P_T、P_I`。需要扰动验证时，按 [扰动实验方法](references/replay-and-amplification.md) 取得实际输入差异方向上的 `S_alpha、C_in_alpha、P_T_alpha、P_I_alpha`，以及不同真实输入上的复测、实际 dtype 下的扰动值、相关离散路由记录。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| 两组同输入比较尚未齐全 | 补齐第 3 节，不以只测一组代替两组证据 |
| 两组同输入接近一致，P_T／P_I 与 C_in 接近或更高 | 分别记录 `PROPAGATION_SUPPORTED`／`ATTENUATION_SUPPORTED`，限定为方向传播／衰减；返回相关上游范围继续第 2 节 |
| 两组同输入接近一致，但任一 P 明显低于 C_in | 记录对应实现的放大迹象，做实际差异方向上的有限扰动和少量其他真实输入验证；两端分别判读 |
| 任一扰动点 S_alpha 暴露可重复局部差异 | 保留该输入和触发条件，进入第 4 节下钻 |
| 受测输入中 S_alpha 持续接近一致，对应 P_alpha 比 C_in_alpha 稳定更低 | 标记 `AMPLIFIER_SUPPORTED`，限定输入／配置／实现范围；回查上游。需要解释放大机制或已有端点证据显示其重要时，再拆内部或进入第 7 节 |
| 扰动未稳定复现放大，或超出可控制的状态范围 | 保留迹象与限制，不升级结论；继续追踪上游，必要时第 6 节 |

没有放大迹象时不强行遍历大量扰动。仅原始跨端输出不同不能证明放大；同输入近似一致也不证明所有输入下相等或没有尺度差异。输入包含多个变量时，按实验控制范围限定解释。

## 6. cosine 无法解释差异时启用辅助指标

**取得的指标。** 按 [辅助指标计算](references/capture-and-metrics.md) 补充范数比、相对 L2、最大绝对误差、logits／目标 logprob 差异；需要时按 [层内观测方法](references/operator-localization.md) 取得路由 ID、权重、margin 和状态记录。保留原 cosine 与 `fallback_reason`。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| 错位、错误 mask、采集变换或非有限值影响比较 | 修复对应数据／数值问题，重算受影响指标；前向数值问题本身可作为候选调查，不静默删除异常 token |
| cosine 接近 1，但范数、L2、logits 等显示差异 | 用对应辅助指标指向的区间继续第 3、4 节的同输入／递归流程，最终仍经第 7 节验证 |
| 评分处理阶段或目标索引不同 | 返回第 1 节处理受影响比较 |
| 固定轨迹与当前配置中各指标均在声明容差内 | 核对用户场景的 batch、长度、并行或运行阶段等线索；仍未复现时第 8 节报告当前覆盖范围 |
| 缺少进一步可用观测或可控实验 | 第 8 节报告未决区间和下一项明确实验 |

有限子集指标不能替代全体结果；top-k 截断数据不能给出精确全分布 KL。辅助指标不更换有效 token 集，也不跳过同输入与干预验证。

## 7. 验证具体细节的端到端作用

**取得的指标。** 按 [干预方法与产物格式](references/causal-validation-and-report.md) 运行 baseline、单项改动、撤销、额外样本；得到各组局部／同输入指标、预先固定的端点 `E_logp`、P95／P99／max、波动及 `reduction`。默认端点为 mean |Δlogprob|。替换算子时使用该次推理实际收到的输入和状态，不复制原训练轨迹输出。

**根据结果执行。**

| 指标／证据 | 下一步 |
|---|---|
| 局部机制与实验相符，单项端点改善可重复且超出波动，对预定终点有主导影响，撤销复现，额外样本支持 | 标记 `MAIN_CAUSE_CONFIRMED`，第 8 节交付；说明它是来源还是放大机制 |
| 单项作用可重复、撤销及额外验证支持，但影响不主导 | 标记 `CONTRIBUTOR_CONFIRMED`，保留结果并继续其他候选 |
| 局部差异减少但端点没有相应改善，或撤销／复测不支持 | 不认定为端点主因；检查干预覆盖和混杂，返回相关候选或第 4 节缩小机制 |
| 均值改善但尾部恶化 | 分别报告，不宣称整体解决；继续检查触发 token 和其他因素 |
| 多个因素可能相互作用 | 做 A、B、A+B 对照，必要时撤销；允许共同主因，分别报告交互作用 |
| 只做了整模块替换、全局升精度或多个细节同时改动 | 结论限定在改动集合／区间；要指认单个细节，继续缩小实验 |

“主导”由当前任务的端点、波动和实际改善说明，不设跨场景通用比例，也不把排名最大但效果很小的因素强称主因。cosine 距离和不同干预改善率不能相加成固有贡献率。修改放大机制后的改善不能倒推出它是原始误差源；训推前向验证也不自动证明长期 RL 收敛改善。

## 8. 汇总证据并交付

**取得的结果。** 汇总前述步骤的指标、状态、作用角色、适用范围和缺失项，按 [产物格式](references/causal-validation-and-report.md) 写出报告。证据状态只按本文件各步定义赋予，不由参考文档或指标脚本自动生成。
