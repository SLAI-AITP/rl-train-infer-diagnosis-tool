# 干预实验、端点指标与产物格式

本参考给出干预实施、数值计算和文件字段。主因／贡献因素等证据状态及流程结束条件统一由 [SKILL.md](../SKILL.md) 判定。

## 1. 在当前推理输入上实施干预

记录目标算子在该次推理实际收到的完整输入／状态 xI_current。替换实现的调用形式为：

```text
原运行：I_op(xI_current)
改动后：T_op(xI_current)
```

保留上游当前运行生成的输入，目标函数原有输出结构与状态副作用也一并处理。原训练 trace 的 T_op(xT_original) 是另一份输入上的结果，不作为这里的替换返回值。需要输入注入的技术实现见 [插桩方法](instrumentation-guide.md)。

具体实现不能直接替换时，使用有记录的最小实现变体，列明所有改变项及伴随条件。同一变体用于多层时保存各目标实例的全局层号。每项实验在独立配置或可撤销补丁下运行，并在运行前恢复必要状态。

## 2. 实验组与保存内容

固定 policy 快照、rollout token、有效评分集合、原始触发配置和评分口径。

| 运行组 | 实施方法 | 保存内容 |
|---|---|---|
| baseline | 原实现固定轨迹前向 | 局部／端点指标及重复波动 |
| intervention | 只替换所记录细节，其余条件不变 | 同输入及内部点指标、完整轨迹端点、改动集合 |
| revert | 撤销该细节，恢复运行状态 | 同一轨迹的局部和端点指标 |
| extra_samples | 使用未用于选择改动的真实样本 | 样本来源、长度／batch／路由等条件及各实验组指标 |
| A／B／A+B | 分别改变 A、B 和两者 | 每组完整配置、目标实例、局部及端点指标；对应撤销记录 |

局部和完整轨迹运行分别记录输入来源。不同执行路径、shape 或样本组成的运行具有独立条件标识。数据缺失和未执行组标为缺失／未执行，不填示意数值。

## 3. 端点指标与相对变化

目标 token 指标的计算见 [采集约定](capture-and-metrics.md)。默认端点为 E_logp，另保存 P95／P99／max、有符号均值和有效 token 数。

```text
E0 = mean(abs(delta_logprob_baseline))
E1 = mean(abs(delta_logprob_intervention))
absolute_change = E0 − E1
reduction = 1 − E1 / E0
```

E0、E1 使用相同 token 集和评分语义。E0 为零或在记录的数值／运行分辨率内时，reduction 置空并记录原因，仍保存绝对值。保留 reduction 的负值，不裁成 0。不同干预的比例不满足可加性；记录每组原始指标，不将 A 与 B 的比例相加代替 A+B 实测。

每个实验组附重复次数、各次原值、中位数、范围和适用的比较容差。局部 cosine、传播／扰动字段沿用相应参考中的定义，不重命名为端点贡献率。

## 4. 产物文件字段

在任务自己的诊断目录随实验逐步写入；可以链接已有产物，避免复制大权重或 trace。

- `run_manifest.json`：样本来源、两端命令／代码／kernel 版本、权重／数据标识、配置及差异、token／mask 语义、环境、比较精度／容差与依据、运行路径。未知字段明确标注。
- `layer_metrics.jsonl` 或 CSV：scope、操作／语义边界、token 数、C_in／C_out／Dcos／G、前序统计、t、lower、数据有效性、各次复测和原始证据路径；选点及状态字段由主流程填写。
- `experiments.jsonl`：实验 id、当前范围／父区间、选中子区间、假设、固定项、改动项、输入／状态快照、命令、原始结果、证据路径，以及由主流程填写的判读、下一步和状态。复用证据时链接原记录。
- 原始数据、采集／重放适配与补丁：实际文件／函数／行号／commit，调用参数和变更集合。
- `report.md`：采用下面的字段结构，各值引用真实产物。

## 5. 报告字段结构

本节仅定义报告格式，结论内容及状态选择来自 SKILL.md。

1. 当前证据状态、作用角色、适用输入与配置范围。
2. 样本来源、实际训推路径、可比性记录、与历史场景的条件差别。
3. 两端具体文件／函数／kernel／版本及实现差别。
4. 定位过程：每轮 scope、候选指标、选点记录、四组重放、内部观测、进入子区间或返回上游的记录。
5. 传播实验：C_in、P_T、P_I、S_T、S_I、扰动指标及覆盖条件。
6. 干预实验：baseline、改动、撤销、额外样本的端点主指标、尾部和波动。
7. 可复现命令、输入／状态、环境、补丁、未决项和下一项实验。

干预表字段：`实验ID | 具体改动 | n_valid | E_logp | P95 | P99 | max | reduction | 重复范围 | 证据路径`。公式定义、数据缺失标记和数值精度在表旁注明。
